# Allí Nomás

Tienda online y panel de gestión para el emprendimiento Allí Nomás — Cimitarra.

## Stack
- Frontend: React + TypeScript + Tailwind + shadcn/ui
- Backend: Node.js + Express + TypeScript
- Base de datos: PostgreSQL + Prisma ORM
- Auth: JWT + bcrypt

## Apps
- `apps/web` — Landing, tienda y panel admin
- `apps/api` — API REST con autenticación y roles

## Dev
```bash
# Frontend
cd apps/web && npm run dev

# Backend
cd apps/api && npm run dev
```
